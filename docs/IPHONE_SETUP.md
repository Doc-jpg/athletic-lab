# Installing on Eli's iPhone, and the parent side

## Eli's phone (two minutes)
1. Open Safari and go to **https://doc-jpg.github.io/athletic-lab/**
2. Tap **Share** (the square with the arrow), then **Add to Home Screen**, then **Add**. The icon is a navy square with an orange bolt, named "Athletic Lab".
3. Open it from the home screen once while online. From then on it works with no signal.
4. First run: three short steps (name, a look, the parent's name). "Finish setup" is enough; "Finish with three weeks of sample data" fills the app with made-up history to explore, which Settings can remove in one tap.
5. Take the one-minute tour (offered on Today, and always available from Settings or Help).

Android: open the address in Chrome, menu, **Install app**. Same steps after that.

## Every day
Today, **Check in** (what sports, how he feels), then **Start** or skip. Daily Foundations is the optional 3 to 6 minutes on most days. Journal is for one line in his own words.

## Parent mode (Deren)
- Settings, **Enter parent mode**, PIN **7101** (change it in Parent mode, Settings tab). It locks again after ten minutes in the background.
- **This week** tab: alerts (pain, sick, dizzy, stopped workout, tournament day, no rest day), the last seven days, totals.
- **Exercises** tab: mark a weighted exercise's form as checked after watching the first reps; then approve 5 lb (and separately 10 lb) for that exercise. Until then it stays body weight and the row is swapped for wall slides. "Turn off" takes any listed exercise out of sessions.
- **Settings** tab: strength days per week (2 or 3), growth-spurt mode, program restart, daily message on/off, quiet hours, message rotation, device notifications (only while the app is open), clinician-recommended supplement record (off by default; the app never suggests one), parent name and PIN, backup.

## Backups (every few weeks)
Settings, **Back up everything**, then share the file to Files or iCloud Drive (or Mail it to yourself). Restoring on a new phone: install the app, finish setup, Settings, **Restore or merge a backup file**, pick the file, **Replace everything**.

## A parent copy on Deren's phone
Install the app on Deren's phone the same way. On Eli's phone: Settings, **Make a parent pack**, AirDrop or Message it to Deren. On Deren's phone: Settings, Restore or merge, pick the file, **Merge (safe)**. The pack has no private notes and no PINs. Merging the same pack twice changes nothing; a newer record on Deren's phone (an approval, for example) is never overwritten by an older one from the pack. Approvals made on Deren's phone travel back the same way: Back up everything on Deren's phone, merge on Eli's.

There is no server, so this is the sync for now. Remote parent access without a file is Phase 2.

## Notifications
In-app messages always work (one a day on Today, not in quiet hours). Device notifications are optional, need iOS permission, and only fire while the app is open. The app does not promise background alerts.

## If something goes wrong
- A screen shows "Something went wrong": tap Go to Today; data is untouched.
- Forgot the parent PIN: there is no reset without erasing the app (Settings in parent mode, Erase everything). Keep a backup; restoring brings everything back and the new install starts with PIN 7101 again.
- The app says "Running in a browser tab": it is not installed on the home screen; follow step 2 so the browser cannot clear its storage.
